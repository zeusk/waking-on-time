# Waking up on time

A 20-minute interview talk built as a Next.js slide deck: periodic notification fences for
IndirectDisplay adapters, with late-stage reprojection as the motivation.

Checkout live version here - https://zeusk.github.io/waking-on-time

```bash
npm run present        # serves out/ at http://localhost:3000 and opens your browser
```

```bash
npm install
npm run export         # rebuilds out/
```
